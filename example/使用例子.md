# 如何使用MD到HTML转换工具

本文档展示了如何使用MD到HTML转换工具的各种功能。

## 基本使用方法

### 单个文件转换

将单个Markdown文件转换为HTML：

```bash
npx md-to-html-converter --input example/sample.md
```

这将在同一目录下生成 `sample.html` 文件。

### 指定输出路径

```bash
npx md-to-html-converter --input example/sample.md --output dist/输出.html
```

### 转换整个目录

```bash
npx md-to-html-converter --input example --output dist
```

默认情况下，这只会转换目录中的顶级Markdown文件。

### 递归转换目录

要处理所有子目录中的Markdown文件：

```bash
npx md-to-html-converter --input example --output dist --recursive
```

## 高级功能

### 使用自定义模板

```bash
npx md-to-html-converter --input example/sample.md --template example/custom-template.html
```

### 使用自定义样式

```bash
npx md-to-html-converter --input example/sample.md --style example/custom-style.css
```

### 同时使用自定义模板和样式

```bash
npx md-to-html-converter --input example/sample.md --template example/custom-template.html --style example/custom-style.css
```

### 监听文件变化

在开发过程中，你可能希望实时预览转换结果。使用 `--watch` 选项可以监听文件变化并自动转换：

```bash
npx md-to-html-converter --input example/sample.md --output dist/sample.html --watch
```
